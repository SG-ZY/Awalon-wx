# Awalon · 阿瓦隆桌游助手

一个用于线下阿瓦隆桌游的微信小程序。无需携带实体卡牌，由房主使用一台设备即可完成身份发放、任务推进、任务投票和最终结算。

## 功能

- 支持 5–15 人对局，并根据人数自动生成角色阵容和任务配置。
- 支持梅林、派西维尔、忠臣、莫甘娜、刺客、莫德雷德、奥伯伦、湖中仙女、兰斯洛特等角色。
- 房主可设置 9 人局的 3 坏 / 4 坏模式，以及第四车失败条件。
- 支持线上选人和线下组队；线下模式由房主记录任务结果。
- 支持手机投票：车上成员依次使用同一台手机投票，房主点击开票后揭晓结果。
- 好人只能提交任务成功，坏人可选择任务成功或任务失败，并按规则统计失败票。
- 支持长按已有任务车编辑车上成员、标记车长，以及修改失败任务的炸弹数量。
- 自动进入刺杀阶段，刺客或房主可选择目标；结束后展示全员身份和本局记录。
- 支持湖中仙女的阵营查验和查验权传递，以及兰斯洛特的忠诚值变化规则。
- 支持身份卡、角色说明、头像编号、昵称和密码，适合线下传递设备查看身份。
- 支持连续对局的角色重洗与身份保护规则，减少重复拿到相同特殊身份的情况。

## 运行方式

1. 使用微信开发者工具导入项目根目录。
2. 在开发者工具中编译或预览。
3. 当前版本为单机线下主持模式，不依赖云函数或云开发。

## 目录说明

- `pages/index/`：主页面、对局流程和交互逻辑。
- `data/`：角色、阵营、技能和任务规则配置。
- `assets/`：头像等静态资源。
- `app.js`、`app.json`、`app.wxss`：小程序全局配置和样式。

## 说明

本项目用于线下娱乐和桌游辅助。角色能力、任务人数及失败条件以项目中的规则配置为准；发布前请在微信开发者工具中替换为自己的 AppID，并按需配置合法的头像资源和小程序信息。
